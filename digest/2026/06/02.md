- **Microsoft Build 2026 — MAI-Image 2.5, MAI-Voice 2 e MAI-Transcribe 1.5: il keynote porta la seconda generazione della famiglia MAI con editing visivo, 16 lingue per il TTS e il word error rate piu' basso su 25 lingue per la trascrizione**. Satya Nadella apre il keynote di Build 2026 (Fort Mason Center, San Francisco, 2 giugno) con il lancio formale degli aggiornamenti alla famiglia MAI, il portafoglio di modelli multimodali proprietari Microsoft. MAI-Image 2.5 — o 2.5e nella variante veloce — e' il primo modello della serie ad accettare immagini in input oltre che in output, abilitando per la prima volta l'editing; si piazza al terzo posto nella Text-to-Image Arena con 1.254 punti, +72 rispetto a MAI-Image 2.0. MAI-Voice 2 aggiunge 15 lingue (tedesco, due varianti inglese, spagnolo, francese, hindi, indonesiano, italiano, giapponese, coreano, olandese, portoghese, turco, vietnamita, cinese) alla copertura originale solo-inglese, introduce una gamma emotiva piu' ampia (inclusi toni come "arrabbiato", "confuso", "imbarazzato") ed e' il 40% piu' piccolo del predecessore a parita' di fedelta' audio grazie a nuovi codec neurali: target dichiarato e' il deployment on-device (auto, wearable, elettrodomestici). MAI-Transcribe 1.5 e' un aggiornamento incrementale sul modello STT gia' leader per WER su 25 lingue, disponibile in Azure AI Foundry. Sul piano strategico, la terza iterazione della famiglia MAI rafforza l'architettura multi-tenant del portafoglio Microsoft: modelli proprietari per voce, immagine e trascrizione che competono direttamente con Whisper (OpenAI), ElevenLabs e DALL-E 3, riducendo la dipendenza da fornitori terzi anche nei segmenti multimodali. ## Tool & prodotti

- **GitHub Copilot Workspace esce dalla beta al Build 2026 con Fleet mode e Autopilot: l'ambiente di sviluppo agentico di GitHub delega ora task interi — da issue a PR — senza supervisione per-step, estendibile via plugin a Jira, Datadog e ServiceNow**. GitHub Copilot Workspace entra in general availability al Build 2026. Il prodotto e' un ambiente browser-based integrato in GitHub in cui uno sviluppatore descrive un bug o una feature in linguaggio naturale: Workspace genera un piano, modifica i file nell'intero repository, esegue test, interpreta i risultati e apre una pull request. Le novita' della GA rispetto alla preview sono due modalita' operative. Fleet mode abilita l'esecuzione autonoma di task circoscritti senza conferma per ogni step — Copilot lavora sull'issue come worker indipendente. Autopilot mode estende Fleet all'esecuzione schedulata in background senza sviluppatore presente: aggiornamenti di dipendenze, gap di test coverage e drift di documentazione sono i casi d'uso dichiarati. Le Copilot Extensions integrano Jira (lettura issue, scrittura ticket), Datadog (log e alert in context) e ServiceNow (workflow ITSM). La linea che Workspace attraversa e' tra "AI-assisted coding" — il developer e' sempre presente — e "AI-delegated coding" — il developer definisce il task, l'agente lo esegue. Per i team che usano gia' GitHub Actions, Autopilot mode crea un ciclo chiuso: evento di sistema -> trigger autonomo -> PR -> review umana. [Fonte: GitHub Next — Copilot Workspace](https://githubnext.com/projects/copilot-workspace/) — [ChatForest — Build 2026 Recap](https://chatforest.com/builders-log/microsoft-build-2026-recap-windows-agent-platform-project-polaris-copilot-workspace/)

- **GitHub Copilot passa alla fatturazione usage-based il 1 giugno 2026: tutti i piani consumano GitHub AI Credits ($0,01 ciascuno) con allotment mensile incluso, ma alcuni sviluppatori segnalano aumenti di costo 10x-50x — le code completion restano illimitate**. A partire dal 1 giugno, GitHub ha convertito tutti i piani Copilot a un modello a consumo token tramite una valuta virtuale: GitHub AI Credits a $0,01 per credito. Ogni piano include un allotment mensile — Copilot Pro+ ($39/mese) include $39 di crediti, Business ($19/utente/mese) e Enterprise ($39/utente/mese) includono equivalenti. La fatturazione copre input, output e cached token per ogni modello, agli stessi listini API. Per utenti heavy user di Copilot Chat su richieste analitiche o multi-step, il consumo supera l'allotment incluso, generando costi variabili: sviluppatori su Reddit e X hanno condiviso proiezioni che mostrano salti da $29/mese a oltre $700/mese. Code completion e next edit suggestion restano escluse dalla fatturazione AI Credits e rimangono illimitate per i piani a pagamento; la discontinuita' colpisce principalmente la componente Chat e le funzionalita' agentiche. Il cambiamento allinea Copilot al modello a consumo gia' adottato da OpenAI, Anthropic e Google per le rispettive API. - **Azure Agent Mesh in preview al Build 2026: un control plane che federa l'esecuzione di agenti su Windows on-prem, Windows 365 Cloud PC e Azure Arc con routing automatico su latenza e GPU — GA Q4 2026, pricing a consumo per compute agentico**. Azure Agent Mesh risolve il problema piu' immediato degli agenti enterprise dopo il prototipo: un agente funzionante su un laptop non scala automaticamente a cinquecento macchine distribuite su tre sedi. Mesh astrae il deployment: lo sviluppatore usa le stesse API locali, il control plane instrada ogni task al nodo piu' vicino disponibile (latenza + GPU) senza configurazione separata per ambiente. I target in preview sono tre: server Windows on-premises, Windows 365 Cloud PC (desktop virtuali) e device con Azure Arc (inclusi sistemi non-Windows e edge industriale). Il pricing sara' a consumo con un nuovo SKU dedicato all'agent compute, separato dal compute classico. Limite corrente: la federazione multi-sito richiede una sottoscrizione Azure per il layer di orchestrazione; gli agenti completamente air-gapped non sono supportati. GA attesa Q4 2026. [Fonte: aitoolsrecap.com — Azure Agent Mesh](https://aitoolsrecap.com/Blog/microsoft-build-2026-windows-agent-framework-wsl3-azure-mesh) — [Windows News — Agent Platform](https://windowsnews.ai/article/build-2026-microsoft-makes-windows-an-agent-platform-for-ai-developers.420496)
