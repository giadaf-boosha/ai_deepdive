## Paper & ricerca

- **La startup in stealth Accomplish rivela una classe di sandbox escape in Claude Code, OpenAI Codex e Cursor basata su file di configurazione Git malevoli: Cursor e OpenAI correggono in circa una settimana, Anthropic impiega circa 50 giorni e 30 release (11-12 settembre)**. La falla sfrutta il fatto che il file di configurazione Git di un repository puo' nominare un comando che l'agente esegue automaticamente sulla macchina dello sviluppatore appena il repository viene clonato o aperto: il comando gira come utente reale, fuori dal perimetro della sandbox dell'agente e senza alcun prompt di approvazione, a condizione che il repository arrivi con la directory `.git` intatta. Accomplish (fondata da Or Hiltch, Amit Avner e Guy Zipori) ha segnalato la falla ai vendor durante l'estate prima della disclosure pubblica; una ricerca correlata di Manifold Security documenta otto difetti distinti su sette agenti di coding a riga di comando che condividono la stessa dinamica strutturale. Il caso estende la famiglia gia' tracciata in `kb/concetti/agent-sandboxing.md` di canali "considerati sicuri per design" che si rivelano sfruttabili — qui il canale e' la configurazione Git del repository stesso, non un tool di error-tracking (caso Agentjacking, giugno) o la memoria persistente (Memory Heist, luglio) — e il divario nei tempi di patch tra vendor (circa una settimana per Cursor e OpenAI contro circa 50 giorni e 30 release per Anthropic) e' un dato comparativo inedito su come i diversi laboratori rispondono a una disclosure coordinata sullo stesso vettore.
