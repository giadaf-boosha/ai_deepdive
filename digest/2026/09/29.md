## Tool & prodotti

- **Plugin4Shell: una falla zero-click aggira la verifica SHA pinning dei plugin in Claude Code, OpenAI Codex, GitHub Copilot e Gemini CLI; Anthropic e OpenAI corregono, Microsoft e Google no (17-18 settembre)**. Quando un agente installa un plugin, esegue un git checkout ancorato a uno SHA di commit a 40 esadecimali per garantirne l'integrita', ma i quattro agenti non verificano che l'albero di lavoro risultante corrisponda davvero a quello SHA: un attaccante che controlla il repository del plugin puo' creare un branch con nome identico allo SHA fissato e impostarlo come branch di default, ottenendo esecuzione di codice da remoto senza alcuna interazione dell'utente. AIR Security, che ha scoperto la falla, la definisce la prima vera vulnerabilita' di supply chain dell'ecosistema degli agenti AI perche' colpisce il layer di distribuzione — marketplace e repository che alimentano milioni di macchine — invece del modello o dell'agente stesso. Anthropic corregge in Claude Code 2.1.179, OpenAI in Codex 0.146.0; Microsoft non ha ancora rilasciato una patch per Copilot, e Google non correggera' Gemini CLI perche' lo sta dismettendo, lasciando ogni installazione esistente esposta a tempo indeterminato. Il caso estende il filone gia' tracciato in `kb/concetti/agent-sandboxing.md` (Accomplish/.git config, Agentjacking, Memory Heist) con un vettore distinto: qui il canale sfruttato non e' un tool esterno o la configurazione del repository di lavoro, ma il meccanismo di distribuzione dei plugin stesso.
