Il 28 maggio Anthropic pubblica Claude Opus 4.8, aggiornamento del modello flagship con miglioramenti documentati su coding, reasoning, financial analysis e knowledge work. La novita' piu' significativa per gli utenti Claude Code e' Dynamic Workflows, disponibile in research preview per piani Enterprise, Team e Max su Claude Code v2.1.154+: Claude scrive uno script JavaScript che orchestra fino a 1.000 subagenti totali per run (16 in parallelo), la cui esecuzione avviene in background lasciando la sessione utente reattiva. L'architettura sposta il coordinamento fuori dal context window — il piano va nello script, i risultati intermedi nelle variabili dello script, il context riceve solo la risposta finale — e riduce il rischio di overflow su task multi-step a scala di codebase. Caso d'uso dichiarato: migrazione completa da kickoff a merge su centinaia di migliaia di righe di codice, usando la test suite esistente come criterio di accettazione. La seconda aggiunta e' il pannello Effort, che consente di specificare la quantita' di elaborazione dedicata a una risposta. Fast Mode e' disponibile come opzione separata: 2.5x la velocita' standard a un terzo del costo, senza downgrade a un modello diverso. Il pricing del modello standard rimane invariato rispetto a Opus 4.7. Il modello e' disponibile su Claude.ai, API e, dalla stessa data, come opzione GA su GitHub Copilot. Anthropic conferma che Mythos-class models restano "in the coming weeks" senza data specifica. ## Tool & prodotti

- **Google lancia il Google Pay & Wallet Developer MCP Server in Public Preview: uno strumento MCP ufficiale che porta le API di pagamento direttamente nell'ambiente di sviluppo degli agenti AI, con accesso a documentazione, gestione integrazioni e metriche di performance in tempo reale**. Il 28 maggio Google pubblica il Google Pay & Wallet Developer MCP Server, un server MCP ufficiale che espone funzionalita' di Google Pay e Google Wallet come tool per agenti AI e assistant di sviluppo compatibili con il Model Context Protocol. Il server consente a un agente di: cercare nella documentazione ufficiale con campioni di codice aggiornati, controllare lo stato delle integrazioni e abilitare API, accedere a metriche aggregate e log di errore, e gestire pass emitters per Google Wallet. La disponibilita' e' in Public Preview con GA prevista entro l'anno. Il lancio fa parte di una strategia piu' ampia: nello stesso ciclo Google ha reso disponibili MCP server gestiti per altre API cloud ("Google-managed MCP servers are available for everyone"), segnalando l'adozione strutturale del protocollo MCP per esporre servizi production-grade ad agenti AI. Per gli sviluppatori che integrano pagamenti in applicazioni agentiche, il server elimina la necessita' di costruire wrapper manuali sulle API REST e centralizza la surface informativa nel contesto dell'agente. Il 28 maggio IBM e Red Hat annunciano Project Lightwell, un impegno quinquennale da $5 miliardi che combina oltre 20.000 ingegneri con capacita' di AI frontier per creare un clearinghouse enterprise dell'open source sicuro. Il progetto usa modelli AI avanzati — ispirandosi esplicitamente ad Anthropic Project Glasswing e OpenAI Trust Access for Cyber — per validare e testare fix di vulnerabilita' su un volume di codice open source senza precedenti. Gli early adopter gia' operativi includono undici tra le principali istituzioni finanziarie globali: Bank of America, BNY, Citi, Goldman Sachs, JPMorganChase, Mastercard, Morgan Stanley, Royal Bank of Canada, State Street, Visa e Wells Fargo.
